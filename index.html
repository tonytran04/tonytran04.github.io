Personal project · iOS

Step Accountability

A daily step tracker that reads Apple HealthKit data and makes progress easy to follow with goals, a seven-day history, and consecutive-day streaks.

React NativeTypeScriptHealthKitExpressPostgreSQL
View project on GitHub
What I built

Seven-day synchronization to a Node.js/Express API backed by Supabase PostgreSQL; persistent on-device goals; automatic refresh when the app becomes active; an 8 p.m. local reminder; and Jest coverage for streak edge cases.

Streak calculation accounts for an unfinished current day, while goal changes update completion across Home and History.

Personal project · Web

Job Application Tracker

A personal workspace for organizing a job search. Track companies, roles, application dates, notes, and progress from applied to offer.

ReactTypeScriptVitelocalStorage
View project on GitHub
What I built

Add, edit, and delete applications; update statuses; search by company or role; filter results; and keep notes and job links alongside each application.

Browser storage keeps records between visits. JSON backup export and import make it possible to move records between computers, with input validation and duplicate-ID handling.

Runs locally in the browser. Records stay on the device; there is no account or automatic cloud synchronization.
